# 🎓 UniConnect2026

### Conecta. Organiza. Participa.

UniConnect2026 es una plataforma web diseñada para conectar comunidades universitarias mediante la creación, exploración y gestión de eventos académicos, culturales, deportivos y sociales.

El proyecto busca integrar tecnología blockchain de Solana para generar registros de participación verificables y reconocimientos digitales.

## 🎯 Objetivo general

Desarrollar una plataforma digital que facilite la organización de eventos universitarios y permita gestionar las inscripciones y participaciones de los estudiantes mediante tecnología blockchain.

## ❗ Problemática

La información sobre eventos universitarios suele encontrarse dispersa en diferentes redes sociales y medios de comunicación. Esto dificulta su consulta, organización y seguimiento.

UniConnect2026 propone centralizar estas actividades en una sola plataforma.

## 🚀 Funcionalidades principales

- Exploración de eventos universitarios.
- Creación y administración de eventos.
- Inscripción de estudiantes.
- Consulta del historial de actividades.
- Registro verificable de participación.
- Reconocimientos y certificados digitales.
- Integración con wallets de Solana.

## 🛠️ Tecnologías previstas

- Solana
- Rust
- Anchor Framework
- React
- TypeScript
- Tailwind CSS
- GitHub

## ⛓️ Blockchain

La plataforma utilizará Solana para almacenar registros verificables de eventos y participaciones.

Se contempla el uso de cuentas PDA para administrar la información de eventos e inscripciones.
